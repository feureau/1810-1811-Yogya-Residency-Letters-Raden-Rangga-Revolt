### Header & Archival Classification
* **Top Center (Red Bleed-Through):** Reverse show-through of `5 Jan. 1811`
* **Margin (Left):** `SEMARANG ENCLAVES GROBOGAN SÈLA KUWU-WIRASARI` / `BOYOLALI ENCLAVE COURT` / `BLORA GROBOGAN JIPANG` / `MALANG ANTANG TO PB IV` / `JIPANG JAPAN` / `GALUH CAUWER WETAN` / `TOLLGATES` / `SOLO R. TOLLGATE` / `COMMERCE JAZAK` / `NO NEW TOLLGATES` / `BOYOLALI KLATEN FORT`
* **Document Subject:** Territorial swaps (Semarang/Demak enclaves, Blora, Grobogan, Jipang, Japan vs. Boyolali, Malang/Antang, and Galuh), tollgate removals along the Solo River, fort upkeep obligations at Boyolali and Klaten, and road/bridge engineering specifications (5 roods wide, 20-foot bridges).
* **Physical Characteristics:** Ruled white notebook folio paper; two punch holes on right margin with rust oxidation stains; blue ink handwriting with red ink double margin marks at bottom metrological note.

### Two-Column Transcription (Margin Notes / Javanese Script vs. Main Text / Dutch Translation)

| Margin Notes / Javanese Script | Main Text / Dutch Translation |
| :--- | :--- |
| **SEMARANG ENCLAVES**<br>**GROBOGAN / SÈLA**<br>**KUWU–WIRASARI** | • **Article 4:** Dutch Govt. [Government] to be given pieces of land belonging to courts in area of Semarang and Demak / also crown lands (*kronlands*) enclaved in Landdrostship of Japara and Grobogan / Wirosari / Waru, and lands between these provinces and Salatiga. |
| **BOYOLALI ENCLAVE COURT** | • **Article 5:** Dutch Govt. in return to give to Yogya / Sala lands belonging to Govt. in Boyolali area. |
| **BLORA / GROBOGAN / JIPANG** | • **Article 6:** Blora / Grobogan / Jipang to be ceded to Dutch Govt. from Sala. |
| **MALANG / ANTANG TO PB IV** | • **Article 7:** In return Sunan [Sunan Pakubuwana IV] to get Malang / Antang. |
| **JIPANG / JAPAN** | • **Article 8:** Jipang / Japan to Dutch from Yogya. |
| **GALUH / CAUWER WETAN** | • **Article 9:** In return Yogya to get Galuh / Cauwer Wetan. |
| **TOLLGATES** | • **Article 10:** Tollgates in ceded territories can be *verlegt* [relocated] / removed to territories now under control of courts. |
| **SOLO R. TOLLGATE** | • **Article 11:** Govt. to remove tollgate maintained for a few years now on Solo River. |
| **COMMERCE JAZAK** | • **Article 12:** Dutch Govt. will favour (free) traffic on Solo R. [River] and will receive the recommendations of the Princes about this. |
| **NO NEW TOLLGATES** | • **Article 13:** No proposals to place tollgates by Govt. on lands bordering on lands of Princes. |
| **Salatiga / Ungaran Forts** | • **Article 14:** Dutch Govt. on own cost will keep up forts at Salatiga / Ungaran. |
| **BOYOLALI / KLATEN FORT** | • **Article 15:** Sunan to pay for upkeep of fort at Boyolali; Yogya to pay for upkeep of fort at Klaten. |
| **Road & Bridge Standards**<br><br>*(Red ink double margin marks)* | • **Article 16:** Roads from Jambu to Yogya / Yogya–Sala / Sala–Semarang to be kept up by Princes in a passable state, 5 Roods wide (Rood Eng. [English] / Scot. = 7–8 yards [?]; `(60' ?)`).<br>• *(Researcher metrological note)*: *Webster's Third New International Dictionary*, Vol. III (G. & C. Merriam Co., 1971), p. 1971 — Dutch / S.
